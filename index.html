외부에 웹 페이지 게시하는 방법

무료로 내 토너먼트 안내 웹사이트를 인터넷에 공개해보세요.

Netlify Drop (초간단 추천)

  1. 현재 HTML 파일 코드를 index.html로 저장합니다.
  2. app.netlify.com/drop 접속 후 저장한 폴더를 마우스로 끌어다 놓습니다.
  3. 30초 내에 생성되는 공유 URL을 동료들에게 전송합니다.

GitHub Pages (영구 무료)

GitHub 저장소 생성 후 index.html 업로드 ➔ Settings ➔ Pages에서 Branch 지정 후 저장하면 자신만의 전용 웹사이트 주소가 생깁니다.

데이터가 임시 저장되었습니다.
